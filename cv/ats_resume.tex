\noindent \textbf{Dear Hiring Manager,}

\vspace{0.6em}

I'm gonna be real with you. I don't code for money. I mean yeah, I need food, clothes, a roof. The basics. That's it. Everything else? I just wanna build stuff, break it, fix it, learn something new, and do it all over again the next day. It's not a job for me. It's legit an addiction. A good one, I think.

My journey started like a low level character in an old MMO. I joined this dead Discord server called immunity. No one talked. I thought, what if I build a bot to wake people up? I barely knew Python. But instead of watching tutorials forever, I just... started. That's how I am. I get excited and I can't wait.

First bot was ugly. I added an economy system where people earned virtual coins for each message. It worked kinda. Then concurrent writes crashed it because I used a raw JSON file. Stupid mistake. But I loved every second.

I hopped into databases. MongoDB sharded cluster for fast writes. Then Redis for caching when things got slow. Then PostgreSQL when I needed relations. Each time I learned just enough to make it work, broke something else, then learned more. That cycle is my happy place.

Then I got obsessed with Rust. I built a Data Access Layer with gRPC so my Python bot could talk to Rust fast. Added an Axum API for real money purchases (people actually bought stuff). Then libSQL inside Rust to kill network lag. Every new thing felt like discovering a secret dungeon.

But here's what I'm really excited about lately. AI. I can't stop reading about new AI threads. I'm customizing my own AI agent using Pi mono. Yeah it's still janky but I love it. I'm building workflows that help me code my Discord bot and website faster. Stuff like auto generating boilerplate, summarizing logs, even suggesting refactors. It feels like I have a little wizard helper now.

And I'm also building new games. I can't talk about them yet. Seriously, I promised. But they're gonna be something. The idea is to create a feedback loop with the community. Like, an ultimate community that works buttery smooth. Money flows in booorrrr... well, at least it'll make my co-owner Flame from the Discord community happy XD. That's all I care about. Flame has been there since day one. If I can make him smile, I'm good.

And I'm not gonna lie. I get super excited about everything I build. Like, child level excitement. Dancing in my chair excited. I don't need a big salary. Just enough to survive and keep doing this forever. The rest of my life I wanna spend understanding software, breaking it, rebuilding it, and maybe helping some people along the way.

So yeah. I'm not a perfect developer. I misspell things. Sometimes I forget to commit for days. But I love coding with my whole dumb heart. If your company needs someone who genuinely does this for the love of the game, not for the incentives, I'm your guy.
